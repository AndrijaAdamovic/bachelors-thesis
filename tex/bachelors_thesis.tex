\frontmatterchapter{ABSTRACT}
This thesis provides a detailed examination of Willems' Fundamental Lemma, a fundamental result in the data-based analysis of linear systems.
First, the theoretical foundations required to understand the lemma are presented, together with its proof. The lemma is then validated through various numerical examples conducted in a simulation environment.
The possibility of simulating the future behaviour of linear systems exclusively from recorded data, without any knowledge of their mathematical models, is demonstrated. The applicability of the lemma to certain nonlinear systems is also investigated.
The lemma is subsequently used to design a data-based predictive controller for linear systems by applying optimization methods. The controller is further enhanced through robustification techniques to make it more suitable for practical systems affected by noise and nonlinearities.

\vspace{8mm}
\noindent\textbf{Keywords:} {Willems' Fundamental Lemma, data-based analysis, simulating the future behaviour, data-based control, optimization}

\chapter{Introduction}

This chapter introduces the motivation for exploring the Willems' Fundamental Lemma which is a famous result in data-based approach to control. Literature overview is also presented, it lists 
papers and books that led to the development of the Lemma as well as some extensions and applications that are worth mentioning and are used in the rest of the thesis.


\section{Motivation}
Classical control theory, generally, assumes that a mathematical model of a system is known for controller design. That model is typically found using system identification and/or 
using first principles, i.e., the laws of physics. For complex systems both of those approaches can fail to create a high fidelity model, thus limiting the ability to control those systems with precision.
An alternative to model-based approach is the direct data-based approach to systems theory, which only uses measured data to simulate or control the system, completely avoiding the model. That approach has
gained popularity since the rapid development of computers made data collection and processing relatively inexpensive. Data-based approach is a large field spanning multiple scientific disciplines, most
famous is the development of machine learning, i.e., artificial intelligence. In this thesis we present a valuable result from linear systems theory which has enabled a vast number of significant results in the
data-based approach. That result is called Willems' Fundamental Lemma which was first introduced by Willems et al. \cite{willems2005note}, informally, it states that if a linear system is inputed
a diverse enough input then using the recorded input-output data it is possible to describe (parametrize) every possible combination of inputs and outputs. That is essentially the same role of a model
but using only data. To illustrate how large of an impact the Fundamental Lemma had in the last few years we graphed the number of citations since its publication year until year 2025 in Figure \ref{fig:citations}. In the following sections we will state the famous results and explore its applications to various dynamical systems.

\section{Theoretical Background}
The goal of this section is to provide an introduction to mathematical concepts needed for understanding
the rest of the thesis. We will also present some standard results from linear control systems theory.
\subsection{LTI Dynamical Systems}
Although Willems' Fundamental Lemma stems from the behavioural approach to sytems theory, in this thesis it is formulated using the 
classical state-space LTI system formulation. This formulation is simpler, yet sufficient for the remaining part of the thesis. 

\begin{definition} 
    A discrete-time linear time-invariant (LTI) system is a dynamical system which admits a representation in the following state space form:
    \begin{subequations}
        \begin{align}
            x(t+1) &= Ax(t) + Bu(t), \\
            y(t) &= Cx(t) + Du(t),
        \end{align}
        \label{eq:lti}
    \end{subequations}
    where \(t \in \mathbb{Z}_{\ge 0}\) is the time, \(x(t) \in \mathbb{R}^{n}\) is the state, \(u(t) \in \mathbb{R}^{m}\) is the input
    and \(y(t) \in \mathbb{R}^{p}\) is the output of the system. \\
    The true state space dimension is $n$ and system matrices \(A \in M_n(\mathbb{R})\), \(B \in M_{n \times m}(\mathbb{R})\), 
    \(C \in M_{p \times n}(\mathbb{R})\), \(D \in M_{p \times m}(\mathbb{R})\).
\end{definition}

In the data-based approach, which is considered in this thesis, the matrices defining the state-space model (i.e. the matrices $A, B, C, D$) are  generally unknown. However, 
we will often assume that an upper bound on state space dimension is given, i.e., we know some $N \in \mathbb{N}$ such that $N \geq n$. The concept of a system trajectory is defined next.

\begin{definition}
    A sequence of ordered triples \(\left( u(t), x(t), y(t) \right)_{t=0}^{\infty}\) is called an input-state-output trajectory
    if 

    \[ \begin{bmatrix} x(t+1) \\ y(t) \end{bmatrix} = \begin{bmatrix} A & B \\ C & D  \end{bmatrix} 
    \begin{bmatrix} x(t) \\ u(t)\end{bmatrix}, \quad \forall t \in \mathbb{Z}_{\geq 0}\]

\end{definition}

It can be deduced that, from linearity of \eqref{eq:lti}, any linear combination of input-state-ouput 
trajectories is itself an input-state-output trajectory i.e. the set of all such trajectories spans a vector space over $\mathbb{R}$.
That space is called the \textit{behaviour} [todo ref] of the system.
 
Additionally, from time invariance \eqref{eq:lti} it can be deduced that if \(\left(u(t), x(t), y(t)\right)_{t=0}^{\infty}\) is a trajectory, then:

\[\left( u(t + \tau), x(t + \tau), y(t + \tau) \right)_{t=0}^{\infty}\]

is also an input-state-output trajectory for all \(\tau \in \mathbb{N}\).
\begin{definition}
    A sequence of ordered pairs \(\left( u(t), y(t) \right)_{t=0}^{\infty}\) is called an input-output trajectory if 
there exists a sequence of states \(x: \mathbb{Z}_{\ge 0} \to \mathbb{R}^{n}\) such that \(\left( u(t), x(t), y(t) \right)_{t=0}^{\infty}\) 
is an input-state-output trajectory.
\end{definition}

In practice we are limited to work with finite sequences of data, so we
need to take a snippet of the trajectory relevant to us. Motivated by that we state the next definition.

\clearpage
\begin{definition}
    Let \(i,j \in\ \mathbb{Z}_{\ge 0}\ \) such that \(i \leq j\). Given an input-state-output trajectory  \(\left( u(t), x(t), y(t) \right)_{t=0}^{\infty}\),
    the sequence  \(\left( u(t), x(t), y(t) \right)_{t=i}^{j}\) is called a \textit{restricted input-state-output trajectory}. Restricted 
    input-output trajectories are defined in the same way.
\end{definition}

\subsection{Contollability and Observability}

In this section the concepts of controllability and observability are defined. Continuing in line with the state-space representation\eqref{eq:lti} from the previous section,
we define controllability and observability in the same framework. However, although the classical and behavioral notions of controllability 
and observability are closely related, they are not unconditionally equivalent. Their equivalence depends on how the behavior is represented. 
In particular, when considering input-output behavior, equivalence with the classical state-space definitions typically requires a minimal realization; 
for the full input-state-output behavior, the correspondence is more direct. We will omit those comparisons between approaches, while more on that 
topic can be found at (TODO: link za clanak/knjigu).

\begin{definition}
    A discrete LTI system \eqref{eq:lti} is called controllable if for any initial state $x(0)$ and any desired state $x_f$, there exists
    a finite-length sequence of inputs 
    \[u(0), u(1), ..., u(T-1)\]
    such that the system reaches \(x(T) = x_f\). Otherwise, the system is said to be uncontrollable.
\end{definition}

In lays terms, the definition above states that any state of the system can be reached from any other initial state in a finite time $T$ by applying finitely many inputs. 

Next state the famous result for testing system controllability stated and proven by Rudolf. E. Kalman. Let the pair $(A, B)$ be the pair of matrices from \eqref{eq:lti} and let $n$ denote 
the true state space dimension of the system.

\begin{theorem}(Kalman controllability theorem)
    The pair $(A, B)$ is controllable if and only if the controllability matrix
    \[ \mathcal{C} = \begin{bmatrix} B & AB & A^{2}B & \cdots & A^{n-1}B\end{bmatrix}\]
    is of full column rank.
    \label{thm:ctrb}
\end{theorem}

The the concept of observability is defined next.

\begin{definition}
    A discrete LTI system \eqref{eq:lti} is called observable at $t = 0$ if there exists a finite time $T$ so that an arbitrary initial state x(0) can be uniquely reconstructed from a known 
    restricted input-output trajectory \(\left(u(t), x(t), y(t) \right)_{t=0}^{T-1}\). Otherwise, the system is said to be unobservable.
\end{definition}

Using time-invariance of \eqref{eq:lti} it can be shown that if the system is observable at $t = 0$ then for every  \(t \in \mathbb{Z}_{\ge 0}\) the state $x(t)$ is reconstructible.
This result is important to control theory when it comes to state estimation (for example Kalman filter) because it gives a necessary condition for exact state estimation.

The following theorem presents a constructive test for observability.

\begin{theorem}(Kalman observability theorem)
    The pair $(C, A)$ is observable if and only if the observability matrix
    \[ \mathcal{O} = \begin{bmatrix} C \\ CA \\ CA^{2} \\ \vdots \\ CA^{n-1}\end{bmatrix}\]
    is of full row rank.
    \label{thm:obsv}
\end{theorem}

The Kalman criteria for controllability/observability were stated but, there are more different equivalent
statements of which the most used ones are the Popov-Belevitch-Hautus (PBH) tests [todo ref].

From Theorems~\ref{thm:ctrb} and~\ref{thm:obsv}, a duality between observability and controllability matrices can be seen and
it is not hard to show that using matrix operations we have:
\begin{align*}
    (A, B) \ \mbox{is controllable} &\iff (B^T, A^T) \ \mbox{is observable}.
    \intertext{Similarly,}
    (C, A) \ \mbox{is observable} &\iff (A^T, C^T) \ \mbox{is controllable}.
\end{align*}

\subsection{Persistency of Excitation}
For the Willems' Fundamental Lemma to hold we need the so-called persistently exciting input. Loosely speaking, Persistency exciting input is
a rich and diverse enough input such that all modes of the system are expressed in the output.

\subsection*{Hankel Matrices}
For a sequence of vectors $(s(t)_{t=i}^{t=j})$ from time $t = i$ to $t = j$, where $i < j$, we use the following abbreviation:

\[s_{[i, j]} := \begin{bmatrix} s(i) \\ s(i+1) \\ \vdots \\ s(j) \end{bmatrix}.\]

In this remainder, this notation will be used to appropriately vectorize trajectories of inputs($u$), states($x$) and outputs($y$).

Hankel matrix is a matrix whose entries are constant on the anti-diagonals, what is contrast to
Toeplitz matrix whose entries are constant on the diagonals. Informally, Hankel matrix is
a mirror image of a Toeplitz matrix.


\begin{definition}
    Given an $T \in \mathbb{N}$, lets consider a restricted input-output trajectory \((u_{[0, T-1]},\allowbreak y_{[0, T-1]})\) of \eqref{eq:lti}. Hankel matrices
    of depth $L \in \{1, ..., T\}$ of these inputs and outputs are given by:

    \[H_{L}(u_{[0, T-1]}) = 
    \begin{bmatrix}
    u(0) & u(1) & \cdots & u(T-L) \\
    u(1) & u(2) & \cdots & u(T-L+1)\\
    \vdots & \vdots &  & \vdots \\
    u(L-1) & u(L) & \cdots & u(T-1)
    \end{bmatrix},\]

    \[H_{L}(y_{[0, T-1]}) = 
    \begin{bmatrix}
    y(0) & y(1) & \cdots & y(T-L) \\
    y(1) & y(2) & \cdots & y(T-L+1)\\
    \vdots & \vdots &  & \vdots \\
    y(L-1) & y(L) & \cdots & y(T-1)
    \end{bmatrix}.\]

    \label{def:hankel}
\end{definition}

In the remainder, we will ofter stack input and output Hankel matrices to obtain a single block Hankel matrix, as follows:
\begin{equation}
    \begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]}) \end{bmatrix} \in M_{(m+p)L \times (T-L+1)}(\mathbb{R}),
    \label{eq:hankel}
\end{equation}

which will be used in various computational tasks.
It is now obvious that every column of the matrices from \eqref{eq:hankel} is a restricted input-output trajectory.
Next, definition of persistently exciting input is presented.

\begin{definition}
    Given an sequence of inputs $u_{[0, T-1]}$ and \(k \in \{1, ..., T\}\), we say that
    the sequence of inputs is persistently exciting of order k if the Hankel matrix 
    $H_{k}(u_{[0, T-1]})$ is of full row rank.
\end{definition}

We have layed out all the necessary definitions and theorems needed for the statement of the main topic of this 
thesis, the Willems' Fundamental Lemma.

\section{The Willems' Fundamental Lemma}

The main result of the Lemma is that every restricted input-output trajectory of length $L$ of the system can be obtained as a linear combination
of finitely many trajectories which span the whole trajectory space, i.e., the behaviour.

\begin{theorem} (Willems' Fundamental Lemma) Given an LTI system \eqref{eq:lti}, assume the pair $(A, B)$ is controllable and let \((u_{[0, T-1]}, y_{[0, T-1]}), \ T \in \mathbb{N}\)
be it's restricted input-output trajectory. Let \( L \in \{1, ..., T\}\). If the input $u_{[0, T-1]}$ is persistently exciting of order $N + L$ then
\((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\) is a restricted input-output trajectory of \eqref{eq:lti} if and only if
\[\begin{bmatrix} \bar{u}_{[0, L-1]} \\ \bar{y}_{[0, L-1]} \end{bmatrix} = \begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}g \]
for some $g \in \mathbb{R}^{T-L+1}.$

\label{thm:lemma}
\end{theorem}

Original statement and proof was given by Willems et. al [] which uses behavioural framework. For completeness of presentation, we also present a proof of the Fundamental Lemma. This proof idea follows
the proof given in [ref DBCBook], with a difference that in our proof we prove equality of subspaces slightly differently than in the [].
\begin{proof}[Proof of Theorem \ref{thm:lemma}]
    From recursive application of the difference equations \eqref{eq:lti} we obtain the following expression:
    \begin{equation}
        y(t) = CA^{t}x(0) + \left(\sum_{k=0}^{t-1}CA^{t - k - 1}Bu(k)\right) + Du(t),
    \end{equation}
    where $x(0) \in \mathbb{R}^n$ is the initial state. Generally, this could be adapted to any initial state $x_{ini} = x(t_{ini})$ using the time-invariance of the system. Now for the input-output
    trajectory \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\) we can write the result from above in matrix notation like this:
    \begin{equation}
        \begin{bmatrix} \bar{y}(0) \\ \bar{y}(1) \\ \bar{y}(2) \\ \vdots \\ \bar{y}(L-1)\end{bmatrix} = 
        \underbrace{\begin{bmatrix} C \\ CA \\ CA^2 \\ \vdots \\ CA^{L-1} \end{bmatrix}}_\text{$\Omega_L$}x(0) +
        \underbrace{\begin{bmatrix} D \\ CB & D \\ CAB & CB & D \\ \vdots & \ddots & \ddots & \ddots \\ CA^{L-2}B & \dots & \dots & \dots & D\end{bmatrix}}_\text{$\Theta_L$}
        \begin{bmatrix} \bar{u}(0) \\ \bar{u}(1) \\ \bar{u}(2) \\ \vdots \\ \bar{u}(L-1)\end{bmatrix}.
        \label{eq:omegatheta}
    \end{equation}
    Matrix  $\Omega_L$ is the classical observability matrix and  $\Theta_L$ is the block Toeplitz matrix of, so called, Markov parameters. We can write the expression
    \eqref{eq:omegatheta} in a more compact form as follows:

    \begin{equation}
        \begin{bmatrix} \bar{u}_{[0, L-1]} \\ \bar{y}_{[0, L-1]}\end{bmatrix} = \begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix} \begin{bmatrix}x_{ini} \\ \bar{u}_{[0, L-1]} \end{bmatrix}.
        \label{eq:io}
    \end{equation}

    Since on the left side is a general input-output trajectory of length $L$ (assuming time-invariance), we conclude that the space of all such trajectories is spanned by the columns of the 
    \(M := \begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix} \). 
    % \[ \dim(\ker M)\]
    % \[\mbox{rank} \begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix} = dim \ im \begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix} = \mbox{rank}(\Omega_L) + mL \]
    The columns of the Hankel matrix \(\begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]}) \end{bmatrix}\) are input-output trajectories so we conclude that:
    \[im\begin{bmatrix} H_{L}(u_{[0, T-1]})\\ H_{L}(y_{[0, T-1]})\end{bmatrix} \subseteq im\begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix}\]
    To prove the Lemma we need to prove the equality of those spaces. We assume the strict inclusion:
    \[im\begin{bmatrix} H_{L}(u_{[0, T-1]})\\ H_{L}(y_{[0, T-1]})\end{bmatrix} \subsetneq im\begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix}\]
    The expression \eqref{eq:io} can be used to formulate an analog expression using Hankel matrices like this:
    \[\begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]}) \end{bmatrix} = \begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix} \begin{bmatrix} X_{[0, T-L]} \\ H_{L}(u_{[0, T-1]})\end{bmatrix}\]
    Where \(X_{[0, T-L]} := [x(0) \ x(1) \ ... \ x(T-L)]\).
    By our assumption the matrix \(J_L := \begin{bmatrix} X_{[0, T-L]} \\ H_{L}(u_{[0, T-1]})\end{bmatrix}\) must not have full row rank, if it were full row rank than the rank of Hankel matrix on the left would be
    equal to the rank of $J_L$ and thus the image spaces would be equal. That implies that the left kernel of $M$ is non-trivial, in other words,
    there exists a non-zero vector \(v = (a^T, b_{0}^T, b_{1}^T, ... , b_{L-1}^T), \ a\in\mathbb{R}^n, \ b_{i} \ \in\mathbb{R}^{m}\) such that \(vJ_L = 0\). Expanding we get:
    \begin{equation}a^{T}x(t) + \sum_{k=0}^{L-1}b_{k}^Tu(t+k) = 0, \ \ \forall t \in \{0, 1, ..., T-L\} \label{eq:p0}\end{equation} Shifting the above equation by an arbitray $j\in\mathbb{N}$ and solving the difference equations of \eqref{eq:lti} for the shifted state
    (similar to \eqref{eq:io}) we obtain:
    \begin{equation}
        a^{T}A^{j}x(t) +  \sum_{i=0}^{j-1}a^{T}A^{j-i-1}Bu(t+i) + \sum_{k=0}^{L-1}b_{k}^{T}u(t+k+j) = 0
        \label{eq:p1}
    \end{equation}
    We want to remove the state $x(t)$ from the equation, the easiest way to do it is to leverge the Cayley-Hamilton theorem which states that matrix A satisfies it's characteristic polynomial 
    \(p(\lambda) = \lambda^n + \alpha_{n-1}\lambda^{n-1} + ... + \alpha_1\lambda + \alpha_0\);
    \[p(A) = A^n + \alpha_{n-1}A^{n-1} + ... + \alpha_1A + \alpha_0I = 0 \]

    Now, if we take $n+1$ copies of equation \eqref{eq:p1} for each $j = 0, 1, ..., n$, and multiply each one with its corresponding $\alpha_j$ and and sum them all, the terms with $x(t)$ cancel
    as a result of C-H theorem. Now we get the following expression with only the inputs:
    \begin{equation}
        \sum_{l=0}^{n+L-1}\beta_{l}u(t+l) = 0, \ \ \forall t \in \{0, 1, ..., T-L\}
        \label{eq:beta}
    \end{equation}

    The expression for $\beta_l$-s can be computed by equating terms with the sum in which C-H was used and the result is:
    \begin{equation}
        \beta_l := \sum_{j = max(0, l-L+1)}^{min(n, l)}\alpha_{j}b_{l-j}^T + a^T\sum_{j = l+1}^{n}\alpha_{j}A^{j-l-1}B
        \label{eq:beta2}
    \end{equation} 


    Equation \eqref{eq:beta}, by the definition of a Hankel matrix, can be rewritten as:    
    \[\begin{bmatrix} \beta_0 & \beta_1 & \dots & \beta_{n+L-1}\end{bmatrix}H_{n+L}(u_{[0, T-1]}) = 0\]
    Since, $u_{[0, T-1]}$ is persistently exciting of order $N+L$, and $N \geq n$, it is clear that $H_{n+L}(u_{[0, T-1]})$ is of full row rank so we conclude that:
    \[\beta_0 = \beta_1 = ... = \beta_{n+L-1} = 0\]

    From \eqref{eq:beta2} if $l\geq n$ the right sum is empty so \(\beta_n, ..., \beta_{n+L-1}\) depend only on $b_k$-s. Now we get:
    \[\beta_{n+L-1} = \alpha_{n}b_{L-1}^T \underbrace{=}_\text{$\alpha_n = 1$} b_{L-1}^T = 0 \]
    \[\beta_{n+L-2} = b_{L-2}^T + \alpha_{n-1}b_{L-1}^T = b_{L-2}^T = 0 \]
    continuing until $l = n$ we get \(b_0 = b_1 = ... = b_{L-1} = 0\) so the left sum of \eqref{eq:beta2} is 0 and thus for $l \leq n$ the right sum remains. Now:
    \[\beta_{n-1} = \alpha_{n}a^{T}B = a^{T}B = 0\]
    \[\beta_{n-2} = a^{T}(AB + \alpha_{n-1}B) = a^{T}AB + a^{T}\alpha_{n-1}B \implies a^{T}AB = 0\]
    continuing until $l = 0$ we obtain the following result:
    \[a^{T}\underbrace{\begin{bmatrix} B & AB & \dots & A^{n-1}B \end{bmatrix}}_\text{$\mathcal{C}$} = 0\]
    Since (A, B) is controllable then $\mathcal{C}$ is of full rank, and thus \(a = 0 \implies v = 0\). Which contradicts our assumption. Thus:
    \[im\begin{bmatrix} H_{L}(u_{[0, T-1]})\\ H_{L}(y_{[0, T-1]})\end{bmatrix} = im\begin{bmatrix}0 & I \\ \Omega_L & \Theta_L \end{bmatrix}\]
    Which means there exists a $g\in\mathbb{R}^{T-L+1}$ such that for any restricted input-output trajectory \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\) we have:
    \[\begin{bmatrix} \bar{u}_{[0, L-1]} \\ \bar{y}_{[0, L-1]} \end{bmatrix} = \begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}g \]

    The proof above is just the only if direction, however, since each column of the stacked Hankel matrix is an restricted input-output trajectory the 
    if direction follows directly from that.

\end{proof}

Stability of the system is not needed because the Lemma uses finite-horizon trajectories and thus doesn't require boundedness of state as $t \to \infty$, also the observability
is not needed as it can be seen in the formulation and proof. In the proof we have also showed that the matrix:
\[\begin{bmatrix} X_{[0, T-L]} \\ H_{L}(u_{[0, T-1]})\end{bmatrix}\]
is of full rank. Also we have made an indirect assumption regarding row rank for persistence of excitation. For a matrix to have full row rank, a necessary condition is that the number of columns needs to be atleast equal to the
number of rows, thus persistence of excitation condition needs that condition fullfilled. When we impose that condition on $H_{N+L}(u_{[0, T-1]})$ we get that:
\begin{equation}
    T - (N + L + 1) \geq m(N+L) \iff T \geq (m+1)(N+L) - 1
    \label{eq:length}
\end{equation}

So for persistence of excitation the length of initial trajectory $T$ needs to satisfy the condition above for a given $L$. Generally, for a long enough recorded trajectory we can use the Lemma
for a shorter length trajectory. In our Lemma formulation we only used trajectories of length $L$ starting from 0, but it can be shown that the Lemma holds for a general restricted
input output trajectory of length $L$, i.e. for time window of $[i, i + L -1] \ \forall i \in \mathbb{Z}_{\geq 0}$ we have:
\begin{equation}
    \begin{bmatrix} \bar{u}_{[i, i+L-1]} \\ \bar{y}_{[i, i+L-1]} \end{bmatrix} = \begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}g
    \label{eq:fl-i}
\end{equation}

Now we will define the lag \label{lag} $\ell$ of the system. Smallest positive integer $k$ s.t. rank \(\Omega_k = \) rank \(\Omega_{k+1}\), where $\Omega_k$ is the observability matrix from 
\eqref{eq:io}, is called the lag of the system, in other words, the smallest $k$ after which the rank of the observability matrix does not change. Clearly, by C-H theorem, $\ell \leq n$. For an observable system that is the minimal trajectory length such that the initial state
$x_{ini}$ can be reconstructed. It can also be shown that the \(\mbox{rank}(M) = \mbox{rank}(\Omega_L) + mL\), where $m$ is the number of inputs. Since in the right column of $M$ there is an identity matrix
and on the left is the zero matrix than those right columns are linearly independent and none of the left columns cannot be gotten as a linear combination of right columns, thus the rank of M is the rank of right columns - $mL$ added
with the rank of left columns which is the rank of $\Omega_L$.

\subsection{Simple SISO System}

Consider a discrete time LTI system \eqref{eq:lti} with state space matrices:
\begin{alignat}{2}
    A &= \begin{bmatrix} 0.5 & 0.1 & 0.1 \\ 0.1 & 0.4 & 0.2 \\ -0.1 & 0.2 & 0.3\end{bmatrix} \ & B &= \begin{bmatrix} -1 \\ 0.1 \\ 0.7\end{bmatrix} \\
    C &= \begin{bmatrix} 0.1 & 2 & 1.5\end{bmatrix}  \ & D &= \begin{bmatrix} 0 \end{bmatrix}
\end{alignat}


Clearly \(n=3, m=p=1\) and the eigenvalues of A are \{0.5834, 0.4657, 0.1509\} which all have their absolute value less then 1 which means the system is stable. Also 
the controllability and the observability matrix, which are in this case square matrices, have a non-zero determinant. The system is therefore both controllable and observable. 
The length of initial trajectory and length of trajectories for reconstruction are chosen respectively as $T = 50$ and $L = 22$. It can be verified that for $N=n$ the condition \eqref{eq:length} is satisfied.
For the input for this example we are using a randomly generated sequence obtained by using MATLAB's \textit{rand} function. Since the input is random there is a high chance for persistency of excitation. Before
testing the lemma we check the rank of the $H_{N+L}(u_{[0, T-1]})$. We input the random input sequence to the system and record the output data, we then create the Hankel matrix $\begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}$.
Now we generate a new random input-output trajectory of the system \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\). We now use the Hankel matrix and the new data to find the vector $g$. We impose that
as a least-squares problem since the Hankel matrix is generally not square and the system of equations is underdetermined (fewer rows than columns). The objective for a minimization problem is the following:
\begin{equation}
    \mbox{Find} \ g\in\mathbb{R}^{T-L-1} \ \mbox{that minimizes} \norm{\begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}g - \begin{bmatrix} \bar{u}_{[0, L-1]} \\ \bar{y}_{[0, L-1]} \end{bmatrix}}_{2}^{2}
    \label{eq:gmin}
\end{equation}

In MATLAB we solve the following problem using the \textit{lsqminnorm} function, which uses \textit{complete orthogonal decomposition (COD)} rather than \textit{singular value decomposition (SVD)} to compute $g$, however, for our example
both SVD and COD should yield similar results. Now the Lemma states that $g$ should make that norm of the difference equal to zero. That means the $g$ is an exact solution, not an approximation. Computing the norm for the calculated g we
get result in MATLAB:
\begin{equation}
\norm{\begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix}g - \begin{bmatrix} \bar{u}_{[0, L-1]} \\ \bar{y}_{[0, L-1]} \end{bmatrix}} \leq 10^{-10}
\label{eq:norm}
\end{equation}

\clearpage

The norm is not exactly 0 but it is really close, the small error arises from truncation of real numbers due to floating point arithmetic, so we can assume the result is valid. Our reconstructed trajectory is found in the image
of the Hankel matrix created from recorded data.

\subsection{Mechanical MIMO System}
\label{sec:mimo}

In this example we will demonstrate the Lemma on a concrete mechanical system. We will show, like in the last example, that we can reconstruct a trajectory from previously recorded data.

\begin{figure}[ht]
    \centering
    \input{figures/double_spring_mass_damper.tex}
    \caption{Double spring--mass--damper system with force input acting on second mass.}
    \label{fig:double-spring-mass-damper}
\end{figure}

The states of the system are positions and velocities of each mass, the input is a force on the second mass. We chose the output to be a vector of positions of both mass thus this is a MIMO system. Using mechanical equilibrium equations we can get a system of coupled linear differential equations
which can be represented as a continuous state space LTI system:
\begin{align*}
    \dot{x}(t) &= Ax(t) + Bu(t), \\
    y(t) &= Cx(t) + Du(t),
\end{align*}

where

\begin{alignat}{2}
    \label{eq:dsmd-abcd}
    A &= \begin{bmatrix} 
        0 & 1 & 0 & 0 \\ -\frac{k_1+k_2}{m_1} & -\frac{c_1+c_2}{m_1} & \frac{k_2}{m_1} & \frac{c_2}{m_1} \\ 
        0 & 0 & 0 & 1 \\ \frac{k_2}{m_2} & \frac{c_2}{m_2} & -\frac{k_2}{m_2} & -\frac{c_2}{m_2}
    \end{bmatrix} \ \ & B &= \begin{bmatrix}0 \\ 0 \\ 0 \\ \frac{1}{m_2}\end{bmatrix} \\
    C &= \begin{bmatrix} 1 & 0 & 0 & 0 \\ 0 & 0 & 1 & 0\end{bmatrix}  & D &= \begin{bmatrix} 0 \\ 0 \end{bmatrix}
\end{alignat}

For this example the parameters are: $m_1 = 1.0kg,\ m_2 = 0.8kg,\ k_1=120Nm^{-1},\ k_2=180Nm^{-1},\ c_1=1.5Nsm^{-1},\ c_2=2.0Nsm^{-1}$.
The above presented is a continuos state-space model, but we need a discrete model so we need to discretize it. There are many ways of discretizing the continuous model, we will derive the discrete version matrices
$A_d, B_d, C_d, D_d$ using zero order hold (ZOH). Assume sampling period $T_s$, we chose $T_s = 10^{-2}s$. Now we will begin from the solution of the general continuous state space system:

\[x(t) = e^{A(t-t_0)}x(t_0) + \int_{t_0}^{t}e^{A(t-\tau)}Bu(\tau)d\tau\]

\clearpage

Let \(k \in \mathbb{Z}_{\geq 0}\) and \(t_0 = kT_s, \ t = (k+1)T_s\). Define \(x_k:=x(kT_s), \ u_k:=u(kT_s)\). Now we have:
\[x_{k+1} = e^{AT_s}x_k + \int_{kT_s}^{(k+1)T_s}e^{A[(k+1)T_s - \tau]}Bu(\tau)d\tau\]

Now assume \(u(\tau) = u(kT_s) = u_k = const. \ \forall \tau \in (kT_s, (k+1)T_s), \ \forall k \in \mathbb{Z}_{\geq 0}\). This is the ZOH, we assume the input is constant between sampling. After a change of variables
for integration we arrive at this result since B and $u_k$ are constants they can go outside the integral. 
\begin{align*}
    x_{k+1} &= e^{AT_s}x_k + \left(\int_{0}^{T_s}e^{Az}dz\right)Bu_k \\
    y_k &= Cx_k + Du_k
\end{align*}

We can now see that this is essentially \eqref{eq:lti} but where:
\[A_d = e^{AT_s}, \ B_d = \left(\int_{0}^{T_s}e^{Az}dz\right)B, \ C_d = C, \ D_d = D\]

This was a general derivation, in MATLAB we use the function \textit{c2d} to convert the system from continuos to discrete time. Now we can see that $n=4, \ m=1, \ p=2$. The initial trajectory we recorded
is 30 seconds long, in MATLAB this was converted to number of samples with \textit{T = round(30/Ts)}. The length of reconstructed trajectories $L$ is 12 seconds. We set $N=n$ because the systems has four 
energy tanks. For the input, instead of a random sequence of real numbers between 0 and 1, we use a pseudo-random binary sequence (PRBS) - a binary signal which jumps randomly between +1 and -1, we multiply
that signal with a positive real number (amplitude) and feed it through a low-pass filter to make it a bit smoother and more realistic. This choice of T, L and N satisfy the \eqref{eq:length}.

\chapter{Data driven simulation of LTI systems}
\label{chp:dd-sim}
In the last section we used the Fundamental lemma to demonstrate that any sufficiently long trajectory of length $L$  can be found
in the image of a Hankel matrix that is built using a previous trajectory with persistently exciting input. This is really interesting, however,
there are no direct use cases when it comes to control. In this section we will build up on the Fundamental lemma and use it to
simulate a future of a given trajectory using the same Hankel matrix.

\section{Problem statement and solution}
Consider the system \eqref{eq:lti} and assume the pair (A, B) is controllable. Let $L_{ini} \in \mathbb{Z}_{\geq 0}$ be the length of past trajectory and suppose we want to simulate the
future trajectory of length and $L_{ref} \in \mathbb{Z}_{\geq 0}$. Let $L:=L_{ini} + L_{ref}$. Assume the following is known:
\begin{itemize}
    \item upper bound $N$ on the state dimension, i.e., $N \geq n$, 
    \item restricted input-output trajectory \((u_{[0, T-1]}, y_{[0, T-1]})\), where $T$ satisfies \eqref{eq:length},
    \item an initial restricted input-output trajectory \((\bar{u}_{[0, L_{ini}-1]}, \bar{y}_{[0, L_{ini}-1]})\),
    \item reference input \(\bar{u}_{[L_{ini}, L-1]}\).
\end{itemize}

We want to calculate the output \(\bar{y}_{[L_{ini}, L-1]}\) such that \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\) is a restricted input-output trajectory of \eqref{eq:lti}. To summarize, based
on the recorded data, the previous history of a trajectory and future input we want to find the future output part of that trajectory. We can split the Hankel matrices of recorded data like this:
\begin{equation}
    \begin{bmatrix} H_{L}(u_{[0, T-1]}) \\ H_{L}(y_{[0, T-1]})\end{bmatrix} = \begin{bmatrix}U_p \\ U_f \\ Y_p \\ Y_f\end{bmatrix},
    \label{eq:uy-pf}
\end{equation}

where $U_p$ and $U_f$ have $mL_{ini}$ and $mL_{ref}$ and $Y_p$ and $Y_f$ have $pL_{ini}$ and $pL_{ref}$ rows, respectively. Next we present a solution of the above described problem,  
as it is done in [TODO: ref DBCBook].

\begin{theorem}
    Consider a system \eqref{eq:lti} with (A, B) controllable and persistently exciting input $u_{[0, T-1]}$ of order $N+L$. Suppose restricted input output trajectory \((\bar{u}_{[0, L_{ini}-1]}, \bar{y}_{[0, L_{ini}-1]})\)
    and reference input \(\bar{u}_{[L_{ini}, L-1]}\) are known. Then the following statements hold:
    \begin{enumerate}
        \item[(i)] There exists $g\in\mathbb{R}^{T-L+1}$ such that: \[\begin{bmatrix}U_p \\ Y_p \\ U_f\end{bmatrix}g = 
                \begin{bmatrix} \bar{u}_{[0, L_{ini} -1]} \\ \bar{y}_{[0, L_{ini} -1]} \\ \bar{u}_{[L_{ini}, L-1]}\end{bmatrix}\]
        \item[(ii)] If $g$ is a solution to (i) then define the output \(\bar{y}_{[L_{ini}, L-1]} = Y_{f}g\). Such defined output
                    makes \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\) a restricted input-output trajectory of \eqref{eq:lti}
        \item[(iii)] If $L_{ini} \geq \ell$ (the lag of the system \ref{lag}) than such output in (ii) is the only one that makes \((\bar{u}_{[0, L-1]}, \bar{y}_{[0, L-1]})\)
                    a restricted input-output trajectory, i.e. it is unique.
    \end{enumerate}
    \label{thm:sim}
\end{theorem}

\section{Simulating LTI system from data}
\label{sec:lti-sim}

Theorem \ref{thm:sim} in fact presents the method of how to simulate the future trajectory of the system, based on the past data. We will test this result on numerical examples. Firstly, we will future output trajectory
for the LTI MIMO example from the previous chapter (\ref{fig:double-spring-mass-damper}). We simulate the system with a PRBS input for 50 seconds ($T_s = 0.01s \ T = 5000$) and recorded the trajectory 
\((u_{[0, T-1]}, y_{[0, T-1]})\). We chose the following lengths of past and future (simulated) part of the trajectory:
\[L_{ini} = 500, \ L_{ref} = 1000, \ L = L_{ini} + L_{ref} = 1500\]

We populated the $H_{L}(u_{[0, T-1]})$ and $H_{L}(y_{[0, T-1]})$ and split them into $(U_p, Y_p, U_f, Y_f)$ parts. Result from (\ref{thm:sim}, (i)) tells us $g$ exists and we calculate it using the modified
least-squares problem from the previous section \eqref{eq:gmin}:
\begin{equation}
    \mbox{Find} \ g\in\mathbb{R}^{T-L-1} \ \mbox{that minimizes} \norm{\begin{bmatrix}U_p \\ Y_p \\ U_f\end{bmatrix}g - \begin{bmatrix} \bar{u}_{[0, L_{ini} -1]} \\ \bar{y}_{[0, L_{ini} -1]} \\ \bar{u}_{[L_{ini}, L-1]}\end{bmatrix}}_{2}^{2}
    \label{eq:sim-gmin}
\end{equation}

Solving with MATLAB's \textit{lsqminnorm} we obtain the vector $g$. Using $g$ we calculate the future output trajectory \(\bar{y}_{[L_{ini}, L-1]} = Y_{f}g\). By theorem (\ref{thm:sim}) this
output part is unique since $L_{ini} \geq \ell = 2 $ (for the parameters given in \eqref{eq:dsmd-abcd}), generally, the lag is unknown, but if we take large enough $L_{ini}$ we can be sure that it is larger.
Next, we compare the data based future output trajectories with one calculated using the system model - the first $L_{ini}$ points using the model. For the input signal we used a multi-sine input like this:
\[u(k) = 10\sin(2\pi kT_s) + \frac{1}{3}\sin(2\pi 3 kT_s), \ k \in \{0, 1, \dots, L-1\}\]

The simulation output presented in Figure \ref{fig:dd-lin}:

\section{Simulating a nonlinear system around equilibrium}
In the last section we showed that it is possible to simulate a LTI system directly from recorded data, without a model. For nonlinear systems, a classical approach is to linearize the 
dynamics around a stationary point around which the linearized model is mostly valid. We want to gather the data around the stationary (equilibrium) point of the system and apply the data-based
simulation of the future trajectory. For this example we will take a classical torque driven pendulum: 

\begin{figure}[htbp]
    \centering
    \input{figures/pendulum.tex}
    \caption{Torque driven simple pendulum}
    \label{fig:pendulum}
\end{figure}

Parameters for the pendulum used in simulations are:
\[m = 0.2\ kg, \ l = 0.5 \ m, \ b = 0.05\ Nms, \ g = 9.81 \ \frac{m}{s^2}.\]

Assuming damping is proportional to angular velocity with proportionality constant $b$, we write the state space dynamics with the state vector \(x = (\theta, \ \dot{\theta})^T\) as follows:

\begin{equation}
    \dot{x} = \dfrac{d}{dt} \begin{bmatrix} \theta \\ \dot{\theta}\end{bmatrix} = \begin{bmatrix} \dot{\theta} \\ \dfrac{-b}{ml^2}\dot{\theta} - \dfrac{g}{l}\sin(\theta) + \dfrac{u}{ml^2}\end{bmatrix} = f(x, u).
    \label{eq:pend-dyn}
\end{equation}

Since this is in continous state space forumlation we need to derive a discrete time version of it. Using sampling period \(T_s = 0.01s\) and assuming
ZOH on the input $u(t)$ (see \ref{sec:mimo}) we discretize \eqref{eq:pend-dyn} using the Runge-Kutta 4 method as follows:
\begin{equation}
    x_{k+1} = x_k + \frac{T_s}{6}(k_1 + 2k_2 + 2k_3 + k_4) ,
    \label{eq:rk4}
\end{equation}
where, 
\begin{align*}
    k_1 &= f(x_k, u_k), \\
    k_2 &= f(x_k + \frac{T_s}{2}k_1, u_k), \\
    k_3 &= f(x_k + \frac{T_s}{2}k_2, u_k), \\
    k_4 &= f(x_k + T_sk_3, u_k).
\end{align*}    

Assuming initial state \(x_0 = (0, 0)^T\) and that the output is the full state of the system ($y_k = x_k$) we supply a pseudo-random binary sequence input for 50 seconds to the system and record the output. We configured the amplitude of the PRBS such that angle $\theta$ is always $\leq \frac{\pi}{18}$ (10 degrees).

\newpage

Since $\theta$ is small enough and the model is approximately linear around 0 we will try to simulte the future trajectory of the system using the Fundamental lemma.
We chose the following trajectory lengths \(L_{ini} = 50, \ L_{ref} = 600 \implies L = 650\), we assumed $N=4$. Since a PRBS input is persistently exciting of order $N + L$  we can repeat the procedure in \ref{sec:lti-sim}.
We give a zero input and set the initial state to $\left(\dfrac{\pi}{10}, 0\right)^T$ for the simulating trajectory - autonomous system.

If we now calculate the norm of the difference between the two output trajectories we get:
\[\norm{\bar{y}_{[L_{ini}, L-1]}^{\ data} - \bar{y}_{[L_{ini}, L-1]}^{\ model}} \sim 10^{-2}\]

Our trajectories do not coincide exactly, but that is to be expected because the model is nonlinear, since the error is small we can say that
data-based simulation works well for small angles. Now we will try simulating with a larger angle and we changed $L_{ini} = 10$. We will also compare

\section{Introduction}

Classical control theory almost always uses a model of the system to synthesise a controller. Usually that model is obtained by system identification from recorded data, but when the model
is too complex to be easily identified or approximated from first principles people started developing control methods based solely on data.
During the last decade, data availability and processing power have been growing rapidly thus data-driven control methods have started do develop intensively. There has also been a lot of progress in the machine learning theory. In this chapter we will build up on
results from the previous sections to create a controller that uses only input/output data, completely bypassing a model. A needed prerequisite for our data-based controller is model predictive control (MPC),

algorithm relies on the Fundamental Lemma since it's result states that it is possible to predict future trajectory of a linear system given input data and recorded data. First formulation (and naming)

\section{Model predictive control}
As mentioned before, MPC is a control algorithm which uses optimization with system model and limitations as constraints to find optimal control input over a finite, receding horizon.
At each time step future trajectory of the system is predicted using the model and optimal sequence of control input is computed taking constraints on inputs and states of the system. Typically, only the first
input of the optimal input sequence is applied after which the procedure is repeated with new measurements. We can say that, other than MPC, we do not have another control solution for multivariable systems with constraints 
on inputs and outputs with stability guarantees. In this section we will formulate classical MPC for LTI systems which is needed in the subsequent section for formulation and understanding of DeePC.

\vspace{1em}

Given an LTI system \eqref{eq:lti}, the classical finite-horizon MPC optimization problem at time step $t$ can be written as:

\begin{equation}
    \begin{aligned}
        \min_{x,y,u} \quad  &\sum_{j=0}^{N-1} \left(\norm{y_j - r_{t+j}}^{2}_{Q} + \norm{u_j}^{2}_{R}\right) \\
        \text{subject to:} \quad &x_0 = \hat{x}(t), \\
        &x_{j+1} = Ax_j + Bu_j, \quad j=0,\dots,N-1; \\
        &y_j = Cx_j + Du_j, \quad j=0,\dots,N-1; \\
        &y_j \in \mathcal{Y}, \quad j=0,\dots,N-1; \\
        &u_j \in \mathcal{U}, \quad j=0,\dots,N-1; \\
    \end{aligned}
    \label{eq:mpc}
\end{equation}


Where: \(\norm{z}^{2}_P := z^{T}Pz\), for a symmetric positive semidefinite matrix P (notation $P \succeq 0$). Matrix \(Q\in M_{p\times p}(\mathbb{R}), \ Q \succeq 0\) is the 
output cost matrix and \(R\in M_{m\times m}(\mathbb{R}), \ R \succ 0\) is the positive definite input cost matrix. Sets \(\mathcal{U} \subseteq \mathbb{R}^m, \mathcal{Y} \subseteq \mathbb{R}^p\) are input and 
output constraints set, respectively. Sequence \((r_0, r_1, ...) \) is the reference trajectory which we want to track, $N\in\mathbb{Z}_{>0}$ is the prediction horizon length. We use estimated state $\hat{x}$ instead of the true state because, generally,
the output is not the whole state i.e. we cannot measure the whole state thus we need to estimate it. This MPC optimization problem is usually a convex quadratic program (QP).
Now we will lay out the MPC algorithm for reference tracking.

\begin{algorithm}
\caption{Model predictive control (MPC)}
\begin{algorithmic}
\Require System model $(A, B, C, D)$; reference trajectory $r$; past input/output data $(u, y)$; contraints sets $\mathcal{U}, \mathcal{Y}$; cost matrices $Q, R$;

\For{$t = 0, 1, ...$}
    \State[1] Estimate $\hat{x}(t)$ from previous input/output data
    \State[2] Solve \eqref{eq:mpc} for $u^{*} = (u^{*}_0, u^{*}_1, ..., u^{*}_{N-1})$ 
    \State[3] Apply input $u(t) = u^{*}_0$ 
    \State[4] Update past input/output data with new inputs/measurements
\EndFor
\end{algorithmic}
\end{algorithm}

This formulation of MPC assumes stationary state inputs are 0, also terminal cost is omitted because when we transfer to DeePC we do not know the full state of the system. 
It can be shown, under typical assumptions, that MPC algorithm is recursively feasable and stabilizing. This algorithm can produce excellent results
if the system model is precise and if it is possible to estimate the initial state $\hat{x}(t)$.


\section{DeePC for LTI systems}
In this section we will formulate predictive control based on data. We will use the same simulation method for prediction from Chapter \ref{chp:dd-sim}.
The following are required for the DeePC algorithm:
\begin{itemize}
    \item[(i)] an upper bound on state dimension $N$,
    \item[(ii)] past/future trajectory lengths $L_{ini}$ and $L_{ref}$, with $L_{ini} \geq \ell$; $L:=L_{ini}+L_{ref}$,  
    \item[(iii)] recorded restricted input-output trajectory \((u_{[0, T-1]}, y_{[0, T-1]})\), where $u_{[0, T-1]}$ is persistently exciting of order N+L and $T \geq (m+1)(N+L) - 1$, $m$ is the number of inputs,
    \item[(iv)] initial (past) trajectory \((\bar{u}_{ini}, \bar{y}_{ini}) = (\bar{u}_{[0, L_{ini}-1]}, \bar{y}_{[0, L_{ini}-1]})\), 
    \item[(v)] reference trajectory $(r_0, r_1, ...) \in (\mathbb{R}^p)^{\mathbb{Z}_{\geq 0}}$, 
    \item[(vi)] input and output cost matrices $Q \succeq 0,\ R \succeq 0$,
    \item[(vii)] constraits sets $\mathcal{U}, \ \mathcal{Y}$, 
\end{itemize}

Requirement (ii) assuemes initial trajectory length longer than the lag of the system which is typicaly unknown. In practice we can simply take long enough initial trajectory for which 
we can be certain that it is longer than the lag. That condition is essentially equivalent to having long past input-output data for initial state estimation in MPC. Now we define matrices
$U_p, U_f, Y_p, Y_f$ like in \eqref{eq:uy-pf}. Conditions above allow for application of Theorem \ref{thm:sim}. We now formulate the DeePC optimization problem at time step $t$:

\begin{equation}
    \begin{aligned}
        \min_{g,y,u} \quad  &\sum_{j=0}^{L_{ref}-1} \left(\norm{\bar{y}_j - r_{t+j}}^{2}_{Q} + \norm{\bar{u}_j}^{2}_{R}\right) \\
        \text{subject to:} \quad & \begin{bmatrix} U_p \\ Y_P \\ U_f \\ Y_f\end{bmatrix}g = \begin{bmatrix} \bar{u}_{ini} \\ \bar{y}_{ini} \\ \bar{u} \\ \bar{y}\end{bmatrix}\\ 
        &\bar{y}_j \in \mathcal{Y}, \quad j=0,\dots,L_{ref}-1, \\
        &\bar{u}_j \in \mathcal{U}, \quad j=0,\dots,L_{ref}-1, \\
    \end{aligned}
    \label{eq:deepc}
\end{equation}

where:
\begin{align*}
    \bar{u} &= col(\bar{u}_0, \dots, \bar{u}_{L_{ref} - 1}), \\
    \bar{y} &= col(\bar{y}_0, \dots, \bar{y}_{L_{ref} - 1}). 
\end{align*}

We deviate from previos nomenclature in favor of easier formulation. Initial trajectory $(u_{ini}, y_{ini})$ will be updated with new meausred data such that it keeps the same length, thus the oldest
data pair will be removed.

\vspace{1em}

We can see that the DeePC optimization problem is \textit{de facto} a MPC problem but where instead of prediction using the model we use previous input-output data, thus this problem aviods the model
completely. We now formulate the DeePC algorithm:

\newpage

\begin{algorithm}
\caption{Data-Enabled predictive control (DeePC)}
\begin{algorithmic}
\Require Requirements (i) - (vii) listed above

\For{$t = 0, 1, ...$}
    \State[1] Solve \eqref{eq:deepc} for the vector g
    \State[2] Compute optimal input sequence $\bar{u}^{*} = U_{f}g$
    \State[3] Apply the first input $u(t) = \bar{u}^{*}(0)$
    \State[4] Update the initial trajectory $(u_{ini}, y_{ini})$ with new inputs/measurements 
\EndFor
\end{algorithmic}
\end{algorithm}

It can be shown that this DeePC is equivalent to MPC under the assumptions of the Fundamental Lemma, i.e. given the same reference and initial trajectory 
they will give the identical output.

\section{Regularized DeePC}
The paper [todo: deepc] introduced robustifications to the DeePC algorithm \eqref{eq:deepc} to make it applicable to realistic systems. We will lay out their results and illustrate them through simulations.
The Fundamental lemma is a result which falls apart when we introduce measurement noise (or nonlinearity) to our system since there is a high probability that the image of Hankel matrix of input-output
data spans the whole space instead of the subspace which is identified with the behaviour of the system. There is an approach where we can maybe remove the noise from recorded data with SVD or similar techniques, that is good for recorded data but for DeePC where
we use real-time data it is not that simple. Now we will formulate regularized DeePC optimization problem:

\begin{equation}
    \begin{aligned}
        \min_{g,y,u, \sigma_y} \quad  &\sum_{j=0}^{L_{ref}-1} \left(\norm{\bar{y}_j - r_{t+j}}^{2}_{Q} + \norm{\bar{u}_j}^{2}_{R}\right) \\
        &+ \lambda_g\norm{g}_2^{2}\ + \lambda_y\norm{\sigma_y}_2^{2}\\ 
        \text{subject to:} \quad & \begin{bmatrix} U_p \\ Y_P \\ U_f \\ Y_f\end{bmatrix}g = \begin{bmatrix} \bar{u}_{ini} \\ \bar{y}_{ini} + \sigma_y \\ \bar{u} \\ \bar{y}\end{bmatrix}\\ 
        &\bar{y}_j \in \mathcal{Y}, \quad j=0,\dots,L_{ref}-1; \\
        &\bar{u}_j \in \mathcal{U}, \quad j=0,\dots,L_{ref}-1; \\
    \end{aligned}
    \label{eq:deepc-reg}
\end{equation}

The hard equality constraint  (i.e. the equality representing data-based prediction) in the original problem can cause problems when noise is added, so we impose a soft constraint with slack variable $\sigma_y \in \mathbb{R}^{pL_{ini}}$
to ensure the feasibility of the constraint. We penalize the 2-norm squared of the slack variable with the weight $\lambda_y \in \mathbb{R}$, while choosing sufficiently large $\lambda_y$ "ensures" that $\sigma_y \neq 0$ only if the constraint
is infeasible i.e. when the data is inconsistent. Two-norm squared regularization on $g$ with weight $\lambda_g \in \mathbb{R}$ is motivated by techniques from robust optimization,see, e.g., [ref] for more details.. 
In the original paper [ref] 1-norm regularization was used, but in a more recent paper [ref] it was updated to 2-norm regularization.

\subsection{Noisy measurements LTI example}

We test the regularized DeePC on \ref{fig:double-spring-mass-damper}. Since this example requires a non-zero input for a non-zero steady state we replace $\norm{\bar{u}_j}^{2}_{R}$ with
$\norm{\bar{u}_j - u_s}^{2}_{R}$ in \eqref{eq:deepc-reg}, where $u_s \in \mathbb{R}^m$ is the steady state input. 
This steady state input is, generally, not necessary for DeePC and it can be calculated from data. 
We calculate the steady state input from the model by solving for $u_s$:
\begin{equation}
\begin{aligned}
    (I-A_d)x_s - B_du_s = 0, \\
    Cx_s + Du_s = y_s,
\end{aligned}
\label{eq:steady}
\end{equation}

where $y_s$ is the desired steady state output. In our example we have $y_s = 1\ m$ and solving \eqref{eq:steady} yields $u_s \approx 71.94\ N$.
We introduce Gaussian measurement noise to the system model like this:
\begin{equation}
    y_k = Cx_k + Du_k + v_k, \ v_k \sim \mathcal{N}(0, \sigma^2)
    \label{eq:noise}
\end{equation}

For this example we took $\sigma = 0.01m$.
Now we run regularized DeePC algorithm to track the steady state.

    \label{eq:nonlinear-spring}
\end{equation}  

Where $\delta l$ is the displacement, and $k_{23} > 0$ the nonlinear spring constant. We chose $k_{23} = 40 \frac{N}{m^3}$, while all other parameters are unchanged from \ref{fig:double-spring-mass-damper}.Thus, the nonlinear dynamics can be written as:
\begin{equation}
    \begin{aligned}
        \dot{x} &= Ax + Bu + E(x_2 - x_1)^3 = f(x, u), \\
        y &= Cx + Du + v_k, \ v_k \sim \mathcal{N}(0, \sigma^2).
    \end{aligned}
    \label{eq:nonlinear-spr-dyn}
\end{equation}

Where $x = (x_1, \dot{x_1}, x_2, \dot{x_2})^T$ is the state vector, $A$ and $B$ are identical as in \eqref{eq:dsmd-abcd}, \(C = [0\ 0\ 1\ 0], \\ D=0$, $E = \begin{bmatrix}
    0 & \frac{k_{23}}{m_1} & 0 & -\frac{k_{23}}{m_2}
\end{bmatrix}^T\).
Since, this is in continuos state space format, we again discretize it using the Runge-Kutta 4 method \eqref{eq:rk4}. The nonlinearity is largely expressed for larger displacements and system
is \textit{de facto} linear for small displacement which can be deduced from \eqref{eq:nonlinear-spring}, i.e., $(\delta l)^3 \approx 0$ for small enough $\delta l$. Choosing $k_{23}$ we can tune how 
much nonlinearity there will be. It is possible for $k_{23} < 0$, then the spring becomes less stiff for larger displacements. Next, we commence the same procedure for designing a DeePC controller
which should track the reference. The steady state input for $y=1 \ m$ can be calculated by solving \eqref{eq:nonlinear-spr-dyn}, we get $u_s \approx 72.96N$.

its considered that it is completely data-based we can say that the result is good. While doing the simulations we have seen that noise has
a more noticable effect when the underlying system is nonlinear. For improved behaviour, [] suggest significant changes to the DeePC algorithm, also Koopman operator approach is being researched 
for potential improvments for (data-based) nonlinear system control.
